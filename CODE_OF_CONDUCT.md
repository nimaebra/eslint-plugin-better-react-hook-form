# Code of conduct

Be respectful and constructive in issues, pull requests, and other project spaces. Critique code and ideas without personal attacks. Harassment, discrimination, threats, and publishing someone's private information are not acceptable.

Maintainers may edit or remove harmful content, close discussions, or restrict participation to keep the project welcoming. Reports will be handled fairly and with respect for the reporter's privacy.

Report conduct concerns privately to the maintainer at **nimaebra75@gmail.com**. Include the relevant links and context, and avoid sharing private details in public issues.
